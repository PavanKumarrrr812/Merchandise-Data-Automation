# 📊 Merchandise Data Automation using Excel VBA

An **Excel VBA automation project** designed to streamline merchandise and inventory data preparation, analysis, and reporting.

The project automates data cleaning, inventory calculations, PivotTable creation, KPI reporting, and interactive dashboard generation through a centralized Excel dashboard.

---

## 🎯 Project Overview

Merchandise and inventory reporting often involves repetitive tasks such as cleaning raw data, calculating inventory metrics, creating PivotTables, and preparing dashboards.

This project uses **Excel VBA** to automate these processes and create a structured workflow from raw data to final reporting.

### Workflow

```text
Upload Dataset
      ↓
Data Cleaning
      ↓
Inventory Calculations
      ↓
PivotTables
      ↓
KPIs & Charts
      ↓
Interactive Dashboard
```

## 📊 Dashboard Analysis

The dashboard provides analysis such as:

* Total Sales Value
* Total Stock Quantity
* Total Inventory Value
* Total Purchase Value
* Average Unit Price
* Low Stock Items
* Warehouse stock
* Top 10 products
* Inventory by category
* Monthly sales
* Supplier purchase value
* Sales by category

Interactive slicers allow users to filter the analysis by **Month, Category, and Warehouse**.

---

## 🧹 Data Cleaning & Change Tracking

The automation handles tasks including:

* Missing and invalid values
* Extra spaces and non-printing characters
* Text standardization
* Product, category, and supplier cleaning
* Stock status standardization
* Quantity and price validation
* Date standardization

The original dataset is preserved, while changes are recorded in a dedicated **Change Log**.

```text
OriginalData
      ↓
CleanedData
      ↓
Changes_Highlighted
      ↓
Change_Log
```

## ▶️ How to Run

1. Download `Merchandise_Data_Automation.xlsm`.
2. Open it using the **desktop version of Microsoft Excel**.
3. Enable macros.
4. Open the Dashboard.
5. Upload a compatible merchandise/inventory dataset.
6. Select the required automation options.
7. Run the automation.
8. Review the cleaned data, PivotTables, KPIs, and dashboard.

The automation is designed for merchandise/inventory datasets containing fields such as:

